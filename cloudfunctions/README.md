# CloudBase 接入与最终配置

当前有可运行的运行层和离线故障验证，**尚未部署真实云函数**。正式业务处理器由 T12～T17/T22/T23 接入。`runtime-example/` 是依赖注入的组合入口，不能单独提供生成服务，也没有伪造的成功结果。

## 本地验证

```sh
npm --prefix packages/cloud-runtime install
npm --prefix packages/cloud-runtime test
```

测试不需要小程序账号、环境 ID、密钥或付费资源。实际 SDK 候选为 `wx-server-sdk@4.0.2`（2026-10-10 查询 npm registry 得到），尚未以真实环境确认其所有返回值/错误码。运行层依赖 SDK 最小结构接口，最终打包时只将 SDK 作为云函数依赖；小程序不能打包它。

## 组合入口

`runtime-example/index.mjs` 导出 `createCloudRuntime(sdk, config)` 与 `createInvocationHandler(runtime, service)`。调用前在可信部署配置中填入 development/production 的不同环境 ID、APPID、经实测的文件 ID 前缀与文档不存在错误码。示例值为空会拒绝启动。配置不从客户端 event 读取。

候选配置模板见 `runtime-example/config.example.json`；实际配置和密钥保留于部署环境。`fileIdPrefix` 必须通过“上传到确定路径 → 返回 fileID → 下载 → 删除”实测证明，不猜测环境/桶名称。生产组合还要求 `platformVerified: true`，仅由最终配置者在下述验收完成后设置。

云函数构建须将 `packages/cloud-runtime/dist` 与正式业务包一同打包（示例使用仓库相对导入，不能原样只上传示例目录）。该入口没有调用 `getTempFileURL`；业务处理器鉴权后按支持的微信私有文件方案交付。真实下载方式/体积限制属于最终平台验收，不能直接把私有文件号当成授权。

## 运行规则

1. 入口用 `getWXContext()` 每次重新取可信身份，匹配 APPID，服务层映射内部用户。任何 event.userId/role/OPENID 都不能代替它。
2. 在事务中登记任务、预留与流水，之后在当前云函数内 `await` 排版、上传和结算，最后返回终态。没有实测过的可靠执行交接时不提前返回“已受理”。查询请求可以并行读取已提交的进行中元数据。
3. 正文只存在当前调用内存。禁止记录 event、布局、原始异常或请求/响应全文；禁止启用平台可重放正文的队列/自动重试。平台自身事件/日志保留行为也须核对。
4. 上传前登记由云端产生的唯一候选路径及 job/batch 关联。`storage.resolve(path)` 恢复文件引用；上传返回值不匹配配置时拒绝并清理已知错误产物，不能继续假定恢复可靠。
5. 对账只查询任务/预留、已有 PDF 与账本。客户端离页/超时不退款；可信期限届满才按当前批次和终态事务收敛。渲染、上传、文件删除禁止放到数据库事务内。
6. 数据库集合与文件默认禁止客户端任意读写，只允许云函数最小权限操作。入口逐次鉴权，前端隐藏管理员入口不提供安全性。

## Owner 最终配置与验收清单

- [ ] 关联小程序账号、开发/生产环境隔离与最小权限；配置云函数依赖、环境与秘密，不提交真实凭据。
- [ ] 对已安装 SDK 验证文档不存在错误码、返回格式、事务冲突/重试/唯一创建行为、分页组合索引；并发请求不超发。
- [ ] 验证 fileID 与路径映射、私有存储规则及鉴权交付；不配置永久公开 URL。
- [ ] 验证页面退出/请求断开/客户端超时不终止云端已开始的函数；若平台终止执行，定时对账能可靠释放或结算。
- [ ] 审查平台事件、函数调用、调试与日志是否保留原始正文载荷，禁用会保存/重放正文的路径。
- [ ] 验证上传后进程中断、提交冲突、迟到上传、函数硬超时及定时恢复，终态与流水保持一致。
- [ ] 用真实 PDF/字体校准超时、内存、页数、文件大小、包体与并发限额；配置定时触发器、错误率/成本告警。
- [ ] 验证微信私有文件打开/下载与真机后台、重新进入记录流程。

这些是最终真实环境验收，不妨碍本地服务、页面与模拟闭环开发。权威规则见 [CLOUDBASE](../docs/CLOUDBASE.md)、[DATA_AND_CREDITS](../docs/DATA_AND_CREDITS.md)。
