# 产品范围与交互

> 状态：讨论基线。正式名称未定；2026-10-09。
>
> 本文回答“给谁用、解决什么、首版做什么”，不定义具体代码和计费参数。

## 1. 用户与定位

主要面向中国大陆的家长、学生和老师。首个业务是**学习纸张生成**：家长可在微信小程序内快速获得合适的纸张，方便微信传播、下载、打印。用户的典型场景低频、临时、追求少步骤，预计主要通过家长互相分享和自媒体自然介绍传播，不以大规模买量为前提。

**纸张生成是第一个工具，不是项目永久的全部功能。** 以后可增加其他学习实用工具，但暂不设计未知功能或通用插件平台。

## 2. 核心用户流程

```text
打开微信小程序
  → 选择纸张模板
  → 使用默认值（必要时选空白 / 填字 / 描红并修改）
  → 分页预览
  → 生成 PDF
  → 在微信中打开、保存、分享、打印
```

**傻瓜式默认即可用**：第一版提供由后台配置、提前计算并验证过的固定纸张版式，不要求用户理解毫米数、格子行列或页边距；不开放会造成残格、溢出和内容截断的任意尺寸设置。仅在确有特殊需求时展开少量可安全调整的文字或样式选项。**每种模板只展示一种默认纸张规格**，不给普通用户「大格版/小格版/标准版」选择。

### 首版正式模板

首版四种纸张类型与固定几何尺寸已确认（[详细规格](PAPER_PRESETS.md)）；**无需用户选择尺寸**：
- 作文方格纸：整页铺方格；默认标题居中、正文自然换行、段首空两格（都是通用能力的默认组合）
- 田字格：外框与中心辅助线
- 米字格：田字格及斜向辅助线
- 拼音四线三格：用户直接输入拼音（如 `nǐ hǎo`），系统排版到四线三格中；首版**不把汉字自动转换为拼音**

四种全部为 A4 竖版；作文方格 10mm、19×27；田字格和米字格 15mm、12×17；拼音四线三格 4mm 线距、6mm 组间距、14 组。字体、辅助线深浅和打印机兼容性仍需测试。

未来按需求再增加拼音田字组合、英语四线格、横线纸、数学格纸等，不属于已确认首批交付。

### 内容模式与通用排版

**所有纸张在经验证的固定打印版式内完整铺格**，无论是否填字，不提供是否铺满的开关；边缘宁可安全留白，也不画残格或越界。

文本的标题、对齐（例如居中）、首行缩进（例如空两格）、自然换行与段落划分是**独立的通用功能**，不绑定作文纸。田字格和米字格等也允许使用同样的排版功能；区别仅在各格线结构如何承载文本。

- 空白：只生成格线；空白区域不随文本减少。
- 填字：按纸张布局写入内容。拼音纸的输入内容由用户直接提供，允许带声调拼音；程序不负责根据汉字猜测发音。
- 描红：按可控透明度/灰度显示参考字；字形与字体须实测。

## 3. 主要页面

1. **模板首页**：按用途展示常用模板；模板卡直达编辑；可记录最近使用。
2. **统一编辑页**：默认直接展示模板预览、内容模式及相关内容输入，点击即可生成；只有需要时才展开少量进阶设置（如标题对齐、首行缩进、描红深浅、线条颜色）。不提供规格选择，模板仅有一套当前启用的默认规格。不展示自定义格宽、行列数、毫米边距等工程参数。通用文字能力不因模板名称被禁用。
3. **纸张预览页**：保持纸张真实长宽比的分页预览；手势缩放不改变导出物理尺寸。
4. **我的**：剩余生成次数、生成记录、次数包入口（商业化启用后）、反馈和隐私入口。
5. **运营中心**：同一个小程序中的管理员限定页面，只看聚合指标和必要的受控操作。

不开发独立 Web 管理后台；日常管理用小程序，详细管理/运维用 CloudBase 官方控制台。默认规格由后台集中维护，小程序使用已发布的预设而非用户输入任意几何值。

## 4. 导出体验与计次原则

- **首版正式导出仅支持 PDF**，以家长下载打印为核心。Word/DOCX 兼容仅为后续可能的扩展，不作为首版功能。
- 预览与调整不扣次数，**成功完成一次生成任务**才扣一次。
- 同一成功任务的 PDF 在有效交付期内重复下载不重复扣次；未来增加新格式时再定义跨格式交付规则。
- 任务失败释放已预留的次数。
- 分享默认只分享工具/模板入口，不默认发送私人作文正文。

## 5. 账户与未来经营

微信身份无感识别，不强制昵称、头像、手机号、密码。后台保留最少的用户与行为数据，以观察新用户、回访、模板偏好、生成成功率和未来次数包使用情况。

已同意的商业方向：免费额度、可选激励广告、**按需购买生成次数包**，不以周期订阅为主。低频用户买的次数原则上不因自然月结束而被清零；具体期限、数量、价格和平台支付资质后续确定，不写死在 V1 产品里。

## 6. 不在首版范围

AI、OCR、作文批改、社交社区、老师学生关系、复杂个人资料、手机号强制登录、复杂 CMS、通用工具插件平台、独立服务器、EdgeOne、自建运营网站，以及默认云端永久保存文章全文。

商业化模块独立预留，但先完成纸张核心能力与真实打印验证。

## 7. 用户体验验收原则

- 常见模板两三步可预览并生成，不要求先完成个人资料。
- 纸张采用预先验证的尺寸与格数，完整铺格、边缘可留白；打印清晰且绝不裁切文字/格线。正文超过当前页自动续页。
- 失败信息可理解，失败不扣次；用户知道剩余额度。
- 排版设置按内容模式和需求渐进披露；默认不打开设置也能生成，避免把全部开关一次性展示给普通用户。
- 对普通用户只开放少量不破坏打印安全的样式与文字参数；后台可更换当前标准规格，用户无需选择。
