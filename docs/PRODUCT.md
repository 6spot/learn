# 产品范围与交互

> 状态：讨论基线。正式名称未定；2026-10-09。
>
> 本文回答“给谁用、解决什么、首版做什么”，不定义具体代码和计费参数。

## 1. 用户与定位

主要面向中国大陆的家长、学生和老师。首个业务是**学习纸张生成**：家长可在微信小程序内快速获得合适的纸张，方便微信传播、下载、打印。用户的典型场景低频、临时、追求少步骤，预计主要通过家长互相分享和自媒体自然介绍传播，不以大规模买量为前提。

**纸张生成是第一个工具，不是项目永久的全部功能。** 以后可增加其他学习实用工具，但暂不设计未知功能或通用插件平台。

## 2. 核心用户流程

```text
打开微信小程序
  → 选择纸张模板
  → 使用默认值（必要时选空白 / 填字 / 描红并修改）
  → 分页预览
  → 选择支持的格式并生成
  → 在微信中打开、保存、分享、打印
```

默认参数应直接可用。大多数用户无需理解格子毫米数、行列数量或页边距；进阶参数折叠显示。

### 初期模板

首批重点验证：
- 作文方格纸：整页铺方格；默认标题居中、正文自然换行、段首空两格（都是通用能力的默认组合）
- 田字格：外框与中心辅助线
- 米字格：田字格及斜向辅助线
- 拼音四线三格

逐步增加：拼音田字组合、英语四线格、横线纸、数学格纸等。模板具体顺序与默认格宽尚未确定。

### 内容模式与通用排版

**所有纸张都固定铺满有效打印区域**，无论是否填字，不提供是否铺满的开关。

文本的标题、对齐（例如居中）、首行缩进（例如空两格）、自然换行与段落划分是**独立的通用功能**，不绑定作文纸。田字格和米字格等也允许使用同样的排版功能；区别仅在各格线结构如何承载文本。

- 空白：只生成格线；空白区域不随文本减少。
- 填字：按纸张布局写入内容。
- 描红：按可控透明度/灰度显示参考字；字形与字体须实测。

## 3. 主要页面

1. **模板首页**：按用途展示常用模板；模板卡直达编辑；可记录最近使用。
2. **统一编辑页**：标题/正文输入、通用排版设置与模板的格线专属设置；按模式提供合适默认值并折叠进阶设置，不因模板名称禁用通用文字能力。
3. **纸张预览页**：保持纸张真实长宽比的分页预览；手势缩放不改变导出物理尺寸。
4. **我的**：剩余生成次数、生成记录、次数包入口（商业化启用后）、反馈和隐私入口。
5. **运营中心**：同一个小程序中的管理员限定页面，只看聚合指标和必要的受控操作。

不开发独立 Web 管理后台；日常管理用小程序，详细管理/运维用 CloudBase 官方控制台。

## 4. 导出体验与计次原则

- PDF 是打印基准格式；支持模板对应的可编辑 DOCX，而不是纸张图片的伪 Word。
- 预览与调整不扣次数，**成功完成一次生成任务**才扣一次。
- 同一个成功任务可以按支持情况交付 PDF 和 DOCX，不因格式数或重复下载而重复扣次。
- 任务失败释放已预留的次数。
- 分享默认只分享工具/模板入口，不默认发送私人作文正文。

## 5. 账户与未来经营

微信身份无感识别，不强制昵称、头像、手机号、密码。后台保留最少的用户与行为数据，以观察新用户、回访、模板偏好、生成成功率和未来次数包使用情况。

已同意的商业方向：免费额度、可选激励广告、**按需购买生成次数包**，不以周期订阅为主。低频用户买的次数原则上不因自然月结束而被清零；具体期限、数量、价格和平台支付资质后续确定，不写死在 V1 产品里。

## 6. 不在首版范围

AI、OCR、作文批改、社交社区、老师学生关系、复杂个人资料、手机号强制登录、复杂 CMS、通用工具插件平台、独立服务器、EdgeOne、自建运营网站，以及默认云端永久保存文章全文。

商业化模块独立预留，但先完成纸张核心能力与真实打印验证。

## 7. 用户体验验收原则

- 常见模板两三步可预览并生成，不要求先完成个人资料。
- 格子在打印纸上清晰、齐整；整页空白区域继续保留格线。
- 失败信息可理解，失败不扣次；用户知道剩余额度。
- 排版设置对不同模板按需出现，不把全部开关一次性展示给普通用户。
