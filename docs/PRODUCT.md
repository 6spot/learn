# 产品范围与交互

> 状态：讨论基线。正式名称未定；2026-10-09。
>
> 本文回答“给谁用、解决什么、首版做什么”，不定义具体代码和计费参数。

## 1. 用户与定位

主要面向中国大陆的家长、学生和老师。首个业务是**学习纸张生成**：家长可在微信小程序内快速获得合适的纸张，方便微信传播、下载、打印。用户的典型场景低频、临时、追求少步骤，预计主要通过家长互相分享和自媒体自然介绍传播，不以大规模买量为前提。

**纸张生成是第一个工具，不是项目永久的全部功能。** 以后可增加其他学习实用工具，但暂不设计未知功能或通用插件平台。

## 2. 核心用户流程

```text
打开微信小程序
  → 选择纸张模板
  → 不输入即可出空白纸；输入文字自动填字（需要时开启描红）
  → 分页预览
  → 生成 PDF
  → 在微信中打开、保存、分享、打印
```

**傻瓜式默认即可用**：第一版提供由后台配置、提前计算并验证过的固定纸张版式，不要求用户理解毫米数、格子行列或页边距；不开放会造成残格、溢出和内容截断的任意尺寸设置。仅在确有特殊需求时展开少量可安全调整的文字或样式选项。**每种模板只展示一种默认纸张规格**，不给普通用户「大格版/小格版/标准版」选择。

### 首版正式模板

首版四种纸张类型与固定几何尺寸已确认（[详细规格](PAPER_PRESETS.md)）；**无需用户选择尺寸**：
- 作文方格纸：整页铺方格；默认标题居中、正文自然换行、段首空两格（都是通用能力的默认组合）
- 田字格：外框与中心辅助线
- 米字格：田字格及斜向辅助线
- 拼音四线三格：用户直接输入拼音（如 `nǐ hǎo`），系统排版到四线三格中；首版**不把汉字自动转换为拼音**

四种全部为 A4 竖版；作文方格 10mm、19×27；田字格和米字格 15mm、12×17；拼音四线三格 4mm 线距、6mm 组间距、14 组。字体、辅助线深浅和打印机兼容性仍需测试。

未来按需求再增加拼音田字组合、英语四线格、横线纸、数学格纸等，不属于已确认首批交付。

### 内容模式与通用排版

**所有纸张在经验证的固定打印版式内完整铺格**，无论是否填字，不提供是否铺满的开关；边缘宁可安全留白，也不画残格或越界。

文本的标题、对齐（例如居中）、首行缩进（例如空两格）、自然换行与段落划分是**独立的通用功能**，不绑定作文纸。用户输入或粘贴的换行、空行默认保留；**每次主动回车开启新段并应用首行缩进，连续两次回车额外留一行空白**；自动换行仍属当前段，不重复缩进。不会自动合并、拆分原始段落，也不会改写正文。田字格和米字格等也允许使用同样的排版功能；区别仅在各格线结构如何承载文本。

- **空白（自动）**：无可绘制文字时直接输出整页格线，不必手动选择空白模式。
- **填字（自动）**：有文字时默认正常填字，按纸张布局写入内容。拼音纸允许用户直接输入带声调拼音，程序不猜测读音。
- **描红（主动）**：用户有文字时主动开启，在与正常填字相同的逻辑占位和分页位置绘制浅灰参考字；各模板用字遵循 [D-031 字体分配表](PAPER_ENGINE.md#首版字体分配与描红d-031)，作文方格描红沿用 MiSans，霞鹜文楷 GB 的中文描红限定于田字格、米字格。描红字体不同也不能改变行数、占格或分页。灰度、字号等由后台预设并经实测验证，不向用户提供调节项。

## 3. 主要页面

组件策略按已确认 D-039：微信原生基础组件 + 少量自定义业务组件。D-040 确认默认收起的进阶设置仅含标题对齐、正文首行缩进；正文旁保留主动整理换行、修改预览和撤销流程，具体转换规则仍待 O-014。页面清单、菜单、逐页布局与视觉规范统一见 [UI_DESIGN](UI_DESIGN.md)；D-043 已接受当前稿作为功能开发基线，样式细节后续可调，以下保留已确认的页面职责。

1. **模板首页**：按用途展示常用模板；模板条目直达编辑；可记录最近使用。
2. **统一编辑页**：默认直接展示模板预览与可选文字输入；无字生成空白纸，有字自动填字，只有描红需要用户主动开启。点击即可生成；需要时展开标题对齐、正文首行缩进两项进阶设置。不提供字号或描红灰度调节。不提供规格选择，模板仅有一套当前启用的默认规格。正文旁提供主动触发的「整理换行」，经修改预览后再应用并可撤销，具体转换和撤销边界仍待 O-014。不展示自定义格宽、行列数、毫米边距等工程参数。通用文字能力不因模板名称被禁用。
3. **纸张预览页**：保持纸张真实长宽比的分页预览；手势缩放不改变导出物理尺寸。
4. **我的**：剩余生成次数、[生成记录](#41-生成记录与离页体验d-035)、次数包入口（商业化启用后）、反馈和隐私入口。
5. **运营中心**：同一个小程序中的管理员限定页面，只看聚合指标和必要的受控操作。

不开发独立 Web 管理后台；日常管理用小程序，详细管理/运维用 CloudBase 官方控制台。默认规格由后台集中维护，小程序使用已发布的预设而非用户输入任意几何值。

## 4. 导出体验与计次原则

- **首版正式导出仅支持 PDF**，以家长下载打印为核心。Word/DOCX 兼容仅为后续可能的扩展，不作为首版功能。
- 预览与调整不扣次数，**成功完成一次生成任务**才扣一次。
- 同一成功任务的 PDF 在有效交付期内重复下载不重复扣次；未来增加新格式时再定义跨格式交付规则。
- 任务失败释放已预留的次数。
- 分享默认只分享工具/模板入口，不默认发送私人作文正文。

### 4.1 生成记录与离页体验（D-035）

云端受理生成后返回任务编号，并在“我的 → 生成记录”展示该任务；用户不必留在编辑或生成页面，可以切换页面、离开小程序，稍后查看结果。仅点击生成、尚未确认云端受理时不能展示为已经开始；响应丢失时先查询原请求的受理结果，不能直接创建另一份任务。

双击或网络重试视为同一次生成；修改内容后主动生成、或明确再次生成则是新任务，即使内容相同也按成功任务计次。通过历史记录领取原文件不重新计次。请求号仅为内部实现，不要求用户输入或管理，具体规则见 [D-037](DATA_AND_CREDITS.md#44-请求号参数指纹与幂等d-037)。

记录显示模板名称、提交时间、当前状态，以及成功后的页数、文件有效期或失败后的可理解原因；不把作文正文、用户输入的标题或正文片段作为历史列表内容保存。状态以云端为准，不显示未经测量的虚假进度百分比。

| 展示状态 | 用户可见行为 |
|---|---|
| 等待处理 / 生成中 | 可以离开，稍后重新进入记录页查看；离页和网络中断不会自动取消或退款 |
| 已成功，文件有效 | 打开、下载 PDF；同一任务重复领取不重复扣次 |
| 已失败 | 显示原因和未消费/已释放预留次数；用户需要时重新粘贴并提交新任务，编辑器仍有输入时可复用，不复活旧任务 |
| 已成功，文件已过期 | 明确提示无法继续领取；文件过期不把成功任务改成失败，不自动重新生成或扣次 |

进入记录列表或结果详情时获取最新状态；可见页面存在未结束任务时进行适度刷新，离页/进入后台后停止页面轮询，重新打开再查询云端。轮询停止不影响任务执行。接口逐次校验任务归属，只能查看和领取本人的记录及文件；生成所需的版本更新提示不应无故阻断仍可安全使用的历史查询和已有文件领取。

生成记录保留必要元数据，PDF 仍按短期交付策略保存；记录和文件各自的期限按 O-007 后续确定，不承诺永久下载。按 [D-036 恢复边界](DATA_AND_CREDITS.md#43-不保存正文的恢复边界d-036)，首版不保存正文供自动重试，也不从历史记录恢复原文或无输入重新排版。用户离页不影响已受理的正常执行；若云端最终失败，可再次粘贴生成，失败任务不扣次。

## 5. 账户与未来经营

微信身份无感识别，不强制昵称、头像、手机号、密码。后台保留最少的用户与行为数据，以观察新用户、回访、模板偏好、生成成功率和未来次数包使用情况。

已同意的商业方向：免费额度、可选激励广告、**按需购买生成次数包**，不以周期订阅为主。低频用户买的次数原则上不因自然月结束而被清零；具体期限、数量、价格和平台支付资质后续确定，不写死在 V1 产品里。

## 6. 不在首版范围

AI、OCR、作文批改、社交社区、老师学生关系、复杂个人资料、手机号强制登录、复杂 CMS、通用工具插件平台、独立服务器、EdgeOne、自建运营网站，以及默认云端永久保存文章全文。

商业化模块独立预留，但先完成纸张核心能力与真实打印验证。

## 7. 用户体验验收原则

- 常见模板两三步可预览并生成，不要求先完成个人资料。
- 纸张采用预先验证的尺寸与格数，完整铺格、边缘可留白；打印清晰且绝不裁切文字/格线。正文超过当前页自动续页。
- 失败信息可理解，失败不扣次；用户知道剩余额度。
- 不要求选择空白/填字模式；仅描红需手动开启，未输入文字也能直接生成空白模板。
- 排版设置按需求渐进披露；默认不打开设置也能生成，避免把全部开关一次性展示给普通用户。
- 对普通用户只开放少量不破坏打印安全的样式与文字参数；后台可更换当前标准规格，用户无需选择。
