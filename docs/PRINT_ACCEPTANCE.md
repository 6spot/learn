## 重现本地打印包

先按仓库 setup 和 [字体说明](../assets/fonts/README.md) 恢复固定原始字体；本机需 Node、Python 3、Poppler（`pdfinfo` / `pdffonts` / `pdftoppm`）及 Pillow 11.3.0。可在独立虚拟环境执行 `python -m pip install -r scripts/print-acceptance/requirements.txt`；下方 `python3` 换成该环境解释器。

```sh
npm --prefix packages/pdf-renderer run build
npm --prefix packages/canvas-renderer run build
node scripts/print-acceptance/generate.mjs
python3 -m unittest discover -s scripts/print-acceptance -p 'test_*.py'
python3 scripts/print-acceptance/measure.py
```

输出位于忽略的 `dist/print-acceptance/`：16 份原始 PDF、版本与 SHA-256 的 `manifest.json`、600 DPI PNG、`measurements.json`、屏幕浏览用 `index.html`、本表副本 `OWNER-CHECKLIST.md`。`diagnostics/` 下去格线的 PDF 仅用于隔离字形量测；打印使用顶层原始 PDF，不打印 HTML/缩略图/诊断副本。

工具启动后先使旧通过报告失效，再加载字体/构建依赖或 Pillow；缺依赖、文件被改动或量测失败时不能继续使用旧报告。生成的 Owner 表会将文档链接调整为相对仓库的位置，须保留在上述输出目录中查看。

## 验收矩阵与当前边界

四模板各含 blank、filled、tracing、multipage 四份文件；前三者单页、末者两页。填字/描红同文，含典型汉字结构、末格点号、英数混排和拼音大小写声调、上下伸部、组合字符、空行、跨页末尾内容。

生成工具把同一布局传给 Canvas 和 PDF；对照所有格线、Canvas 实际请求的字体/GID、原点和字号，换 DPR/缩放后摘要与逻辑布局保持不变。按原始合成输入核对全部槽位引用，确保正文和跨页末尾内容没有遗漏或重复。Canvas 使用调用记录器，不能代替实际屏幕像素/真机比较。Poppler 光栅独立于 Fontkit 和两种 renderer，检查主格线的绝对坐标、完整页面墨迹及去格线后的完整字形墨迹。字形区域均须有可见墨迹，但它不是 OCR，重叠区域仍需人工识字检查。

光栅使用 600 DPI，1 px = 0.042333 mm；抗锯齿开启、细线增强关闭。以灰度 < 250 为可见墨迹，边缘允许 2 px（0.084667 mm），中心线允许 1.5 px（0.0635 mm）。墨迹范围取像素单元外边缘，中心取横截面墨量重心。这些只是数字量测误差，**不是实体打印公差或已验证的打印安全区**。

物理规格唯一依据 [PAPER_PRESETS](PAPER_PRESETS.md)。`manifest.json` 记录候选 engine/template/font 版本与样式；`development-candidate` 不等于正式 active。没有修改固定格线、字号、描红灰度或字体分配。PDF 完整嵌入原字体并附带许可证；可视/打印交付不保证复制/提取文本，不代表已经取得所有部署用途许可。

## 本轮数字证据（2026-10-11）

Poppler 26.10.0、Pillow 11.3.0；16 份 PDF 共 20 页，所有页面均为 A4。两档 Canvas 视图与 PDF 共 6,950 段格线、全部字形位置对照通过；同文填字/描红逻辑行和槽位相同。独立测量 166 条主格线、1,251 个有墨迹的字形区域。

| 数字量测 | 最大误差 | 数字容差 |
|---|---:|---:|
| 主格线中心 | 0.014834 mm | 0.0635 mm |
| 完整页面墨迹边缘 | 0.019667 mm | 0.084667 mm |
| 隔离字形墨迹边缘 | 0.068000 mm | 0.084667 mm |

缩略图和拼音局部已浏览，调号、上下伸部和不同描红字体可见；这不是实体打印或规范教学字形认可。量测工具 **7 项回归通过**，覆盖外边裁切/移动、格线消失/偏移、字形无墨迹/越界、灰色描红识别，以及缺少构建模块/Pillow、PDF 哈希变化后旧报告失效。缺字、汉字输入拼音格及重复调号分别明确返回 `MISSING_GLYPH` / `UNSUPPORTED_TEXT`，没有生成部分 PDF。

最大候选文件为 `mi-grid-tracing.pdf`，18,415,385 B，包含完整 MiSans 和霞鹜文楷原始字体；最终服务/真机仍需验证此体积。纸张、字体、内核版本及候选样式详见打印包 manifest，发布许可与资源预算不能由此表推定。
