## 阶段 1：纸张核心技术验证

- [x] Owner 已确认 [四种首版固定纸张规格](PAPER_PRESETS.md)：作文方格、田字格、米字格、拼音四线三格
- [x] 确认无字自动空白、有字默认填字、描红主动开启；填字/描红共享布局，不开放字号/灰度滑块
- [ ] 实测字体、字号、描红灰度与各模板打印效果，定下后台默认值
- [x] 拼音格首版采用用户直接输入拼音（可带声调），不做汉字自动转拼音
- [x] 默认保留输入或粘贴的换行与空行；只有用户主动操作才整理换行
- [x] 一次回车开启新段、两次回车额外留空行、自动折行不重复缩进
- [x] 中文点号在行末采用与最后一个汉字共占末格的唯一处理方式，不设计替代策略
- [x] 英文和数字按真实字形宽度排版；英文单词优先整体换行，不提供多种用户模式
- [x] 长单词超出整行按完整字符边界分行，连续数字与小数点尽量整体保留，空格不改写
- [ ] 继续验证复杂标点、分页、拼音书写线定位和主动整理换行
- [x] 建立纯 TypeScript 四种固定模板的格线几何模块，含 7 项本地测试；此项**不等于文字排版引擎完成**
- [ ] 在格线几何基础上完成文本块定位、段落、占格和跨页布局与基准样例
- [ ] 生成 PDF 并实际打印验证
- [ ] 逐项验证作文格、田字格、米字格、拼音格的安全留白、整页铺格、PDF 打印及超长内容续页
- [x] 字体默认方案已定：MiSans 正常填字、霞鹜文楷 GB 田字格/米字格描红、MiSans Latin 拼音（D-031）
- [ ] 对小学常用字、拼音调号、描红灰度、MiSans PDF 嵌入许可与实际包体积进行验证，确定字重/字号及缺字回退策略

**交付条件**：PDF 实际打印达到验收标准，版式尺寸固定可靠，内容完整且无截断。DOCX 不在此阶段。
