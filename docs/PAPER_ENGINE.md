# 纸张模板与统一排版引擎

> 状态：**规格与基本排版规则已确认，开发进行中**；`packages/paper-core` 已实现四种固定 A4 格线、三种方格模板的基础文字占位及自动分页。拼音字形布局、跨端字体度量、复杂标点、Canvas/PDF 和实体打印仍待实现或验证。固定规格以 [PAPER_PRESETS.md](PAPER_PRESETS.md) 为准，阶段进度以 [ROADMAP.md](ROADMAP.md) 为准。

## 1. 目标

给定同一份纸张描述，输出稳定、可打印的几何布局，首版通过 Canvas 和 PDF 表达，DOCX 仅作为以后可能增加的适配器。模板只定义纸张结构与默认配置，不独占标题、缩进或换行等文字能力。内容是可排列的文本块；通用文字排版规则负责对齐、缩进、自动换行与分页；布局层确定物理坐标；渲染层只负责呈现。完整格线覆盖可打印内容区域是所有纸张模板的固定规则，不是可选开关。

```text
PaperDocument
  ├── pageSpec                 纸张与边距
  ├── templateId/version       模板和版本
  ├── templateOptions          格线、格宽、颜色等
  ├── textStyles               通用标题/段落排版规则
  └── content                  空白 / 填字 / 描红 + 文本块
           │
           ▼
      validate + layout
           │
           ▼
      LayoutPages
           ├── 页面物理尺寸
           ├── 格线/路径集合
           ├── 字形坐标与占格映射
           └── 分页和块结构
              │
       ┌──────┴──────┐
       ▼             ▼
     Canvas          PDF
   （本地预览）    （正式打印）
```

## 2. 输入与输出契约

T03 已将契约落实在 `packages/paper-core`：`PaperInput` 只接受模板 ID、可选标题/正文、描红及两项安全文字设置；`TrustedPaperPreset` 由可信调用方独立提供，包含几何、样式、资源限制和版本组合。`createPaperDocument` 校验并生成不可变输入快照，保留原始文本、UTF-16 字符簇范围及 CR/LF/CRLF 段落边界。渲染器的唯一正式输入为 `PaperLayout`，其字形原点已包含 shaping 偏移。具体签名和错误见 [核心契约](../packages/paper-core/README.md)，不把类型交付当成 T05/T06 排版完成。

坐标沿用既有内核的毫米、页面左上原点，精度固定为 `1e-6 mm`；字体单位在边界统一换算，页面 y 向下、字体 y 向上。Canvas/PDF 只换算输出单位，不重新测宽或分页。下列概念字段描述职责，不是允许客户端传入可信预设的 API：

**输入** `PaperDocument`：
- `templateId` 和 `templateVersion`：标识确定版本的模板预设；同时绑定排版内核与字体/度量资源版本，完整规则见 [共享排版代码与版本匹配](ARCHITECTURE.md#31-共享排版代码与版本匹配d-032)；
- `pageSpec`：取自首版固定 A4 竖版预设，包含格线中心线的定位与几何留白；打印安全区域按 [D-038](PAPER_PRESETS.md#21-中心线墨迹与打印安全区域d-038) 另行验证；**不允许任意放大纸张，也不提供是否整页铺格的开关**。
- `templateOptions`：从模板已验证的版式预设取得格宽/高、行列数、间距、线型、辅助虚线、颜色与粗细；**每个模板只使用一个已发布的默认规格**，不向用户暴露规格选择；也不开放能破坏完整格线和安全边界的自由尺寸设置。
- `content.mode`：引擎内部仍可取 `blank | filled | tracing`，**由输入内容和描红开关推导**，不是要求用户选择三种模式；无可绘制文字为 `blank`，有文字且未开启描红为 `filled`，有文字且开启描红为 `tracing`。
- `content.blocks`：可选标题与正文等逻辑文本块；保留用户显式换行/空行，自动视觉折行不写回原文；
- `textStyles` / 文本块规则：水平对齐（如居中）、首行缩进（如按两个字符格）、自动换行、手动段落/换行、行距等通用排版参数；所有具备文字承载区域的模板都可以使用，而非作文格专属。具体单元度量按格线结构适配。

**输出** `PaperLayout`：按页包含格线、逻辑行/格位、字形 ID/字体/字号/基线/实际墨迹与源范围、样式和版本组合；渲染边界将毫米换算为 Canvas 像素或 PDF pt。`LayoutPages` 是早期示意称呼，不另建一份并行协议。

小程序和云端以相同版本组合运行共享排版内核，云端复算结果须与预览布局摘要一致，Canvas/PDF 分别消费经核对一致的布局。字体和绘制差异仍须由样张与打印结果验证，不能自行改变格宽、换行和分页；版本与摘要机制不能替代字形及打印验收。

## 3. 模板、文字排版、内容分别独立

**模板不是一套封闭功能**，它定义格线结构、可放置文字的区域、默认参数，以及该结构如何解释“一个位置/一行”。以下仅列默认预设，不限制其它文本排版能力的使用：

| 模板 | 格线结构 | 默认呈现（可调整） |
|---|---|---|
| 作文方格 | 方格 | 可选标题居中；正文首行空两格、自动换行 |
| 田字格 | 方格 + 中心横竖辅助线 | 空白/单字练习；也允许标题、段首缩进、连续文字和自动换行 |
| 米字格 | 田字格 + 对角辅助线 | 空白/单字练习；也允许标题、段首缩进、连续文字和自动换行 |
| 拼音四线三格 | 四线三格的行带 | 用户直接输入带或不带声调的拼音并排版；不从汉字自动生成拼音。对齐、缩进、换行等通用规则仍可用，但以文本行带而非字符方格计量 |
| 组合及其他 | 多个格线区域 | 复用通用文字规则，各区域定义自身承载与位置映射 |

**通用文字排版能力**（与模板解耦）：

- **文本块**：标题、正文段落；标题并非作文格特有，用户可为任何模板添加。
- **水平对齐**：左、居中、右；“标题居中”只是对标题块采用居中策略。
- **首行缩进**：每段可配置，以相关文字布局单位衡量；方格类可以空两个格，行带类按行带上的字符排版尺度转换。
- **自动换行**：在内容区域的剩余位置不足时自然续行；适用于田字格、米字格及其他可填字模板，而不是作文格专属。
- **显式段落/换行**：一次回车（一个显式换行）开启新段落并应用该段首行缩进；两次连续回车在段落之间额外保留一行空白。逻辑段落独立于视觉自动折行，自动折行不会重复缩进。
- **内容模式**：内部保留空白、填字、描红三种渲染结果；前端自动判定空白/填字，用户仅需主动开启描红。填字与描红**共用文本布局、占格和分页结果**，描红只替换文字的绘制样式。

**模板预设提供开箱即用的组合**，如作文格默认居中标题和两格首行缩进，田字格默认空白练习；所有适用模板都能复用文字能力。用户端默认只显示可选文本输入、描红开关和生成，少量安全选项按需展开；**不提供空白/填字选择，也不提供字号、描红灰度调节**；不展示具体格宽、行列、边距参数。

**格线类型/排版算法由代码定义，规格与默认值由后台统一维护。** 后台可发布已验证的标准版式预设，小程序不需要更新代码才能获取当前发布的规格；但格线算法发生变化仍需要代码更新。首版不需要大型模板 CMS。后台预设如何存储、审核与发布仍需做最小实现选择。

## 4. 完整铺格与作文样例规则

### 4.1 固定纸张规格与完整、安全的铺格

1. 首版提供**Owner 已确认的四套固定 A4 竖版规格**（详见 [PAPER_PRESETS.md](PAPER_PRESETS.md)）。纸张尺寸、单元宽高、行列/行带数量、定位基准和几何留白以该文档为准；D-038 已明确中心线计量，不得在程序中自行重算成另一套行列。线宽、灰度、打印安全区域与实际公差仍需实测确定。
2. **先按固定中心线坐标生成完整格线，再放文字**。没有“铺满/不铺满”选项；铺格范围是预设的完整书写区域，而不是要求边框延伸到纸张裁切边缘。根据线条样式检查实际墨迹，不能把中心线几何范围当成墨迹裁剪框，详见 [D-038 的量测定义](PAPER_PRESETS.md#21-中心线墨迹与打印安全区域d-038)。
3. **宁留白，不截断**：可用尺寸无法整除完整格子时，保留边缘余量，必要时左右/上下对称分配；不绘制残格、不越过安全边距、不强制缩放既定格宽、不裁掉末端内容。
4. 标题、正文和空白内容使用同一张完整铺格的底纸。文字不能溢出格线或纸张安全边界；行尾文字、标点如不能合法放下应合理换行，而不是裁切。
5. 一页装不下的正文继续生成同样完整铺格的新页面，绝不能因为超过固定行列数而静默丢失。超过产品明确限制的极长内容，应在生成前说明限制并拒绝/引导拆分，不能返回不完整文件。
6. 小程序预览与 PDF 均使用同一组经验证的物理布局参数；预览缩放只改变屏幕显示比例，不改变打印尺寸。

### 4.1.1 建议的预设几何数据

```ts
type PaperPreset = {
  pageSizeMm: { width: number; height: number };
  orientation: "portrait" | "landscape";
  geometryMarginsMm: { top: number; right: number; bottom: number; left: number };
  layout: {
    unitWidthMm: number;
    unitHeightMm: number;
    rows: number;
    columns: number;
    originMm: { x: number; y: number };
  };
};
```

此结构是示意，不要求所有线格都使用行列单元：横线纸和拼音行带需定义相应的固定周期/基线。`geometryMarginsMm` 指纸边到最外侧中心线/端点的几何留白，对应当前内核的 `margin`；当前 `PageGeometry.bounds` 只描述中心线范围，不包含线宽，也不代表已验证的打印安全区域。模板不能为容纳内容或描边而改变物理参数。

### 4.1.2 后台维护的预设与少量用户可改项

用户选择模板时**自动加载该模板唯一正在生效的版式规格**；不展示常规版/大格版等子选项。用户不得传入自定义行列、任意格宽或负边距等未经验证的物理参数。后台维护每种预设的纸张尺寸、格线周期、行列/行带数量、安全边距、定位原点、线条默认样式及可选的文字预设；用户无需做任何规格选择即可直接生成。

按 D-040 将设置分成：
- **后台专业配置**：格线几何、页边距、可打印范围、每个模板唯一当前生效规格；变更必须先检查物理边界并打印验证。
- **普通用户基本输入**：可选标题和正文；无字自动生成空白纸，有文字默认填字，描红仅由用户主动开启。
- **按需展开的安全设置**：首版为标题对齐、正文首行缩进，默认收起；具体允许值随 UI 评审和预设验证落实。文字字号与描红灰度由已发布预设控制，不暴露给普通用户。自然换行与自动分页是固定能力，不提供关闭开关。
- **独立主动文本操作**：正文旁的整理换行必须先预览改动，再由用户应用，并提供撤销流程；具体转换和撤销边界按 D-046，不因布局重算自动整理原文。

每份预设以 `templateId` 和不可变的 `templateVersion` 标识；后台编辑先形成新版本，验证后再发布。**每个模板仅有一个 active 版本**，旧版本为受支持的编辑会话及进行中的生成任务保留，不成为用户可选择的规格。预览与云端生成还须锁定内核和字体/度量资源，不能只绑定预设版本；兼容检查、发布顺序和失配行为以 [ARCHITECTURE 的版本规则](ARCHITECTURE.md#31-共享排版代码与版本匹配d-032) 为准。存储与发布接口仍待实施验证。

### 4.2 作文预设（可在其他格子模板复用）

根据此前两篇 Word 作文的转换经验，作文格**默认**使用：
- 标题居中，标题与正文之间可空行；
- 首行空两格，正文按逻辑段落自然换行；
- 汉字、数字、标点按确定的占格规则放置；中文标点默认占独立格；
- 多页按统一尺寸、边距和格子位置排版。

这些都是通用文字排版能力的参数组合，而不是作文模板独有的实现。田字格或米字格使用相同排版选项时也应得到同等的标题/段落行为。

文字处理需要特别测试：中文引号/括号/句号的禁则、连续数字、英文单词、空格、全角/半角、拼音声调、表情及 Unicode 组合字符。**不能用 `str[i]` 直接将 UTF-16 代码单元当作完整文字。** 英文和数字的宽度测量原则已确认；实际字体度量、超长词安全断行和复杂标点细节仍待验证。

### 4.2.1 方格中文点号行尾处理（已确认）

对作文方格、田字格、米字格等**按格排字**模式，采用唯一一套默认规则：

- 正常情况，中文句号、逗号等点号每个独占一格。
- 当前行最后一格已放置汉字，而紧随其后的句号、逗号等不能位于下一行行首的点号没有独立格子时，**将该点号缩小并与最后一个汉字同置于末格内**。点号应在格内保持可见、清晰，不画出格线，也不放到下一行行首。
- **不实施“将前一个汉字与点号共同挪到下一行”的备选排版分支**；不向用户提供策略选择。
- 原文字符不删除、不合并；共享的是显示位置，不是把两个字符改写为一个字符。格线的物理尺寸保持不变。
- T05 按 D-047 将开引号/括号绑定后一个字符簇，普通闭引号/括号绑定前一个单元，双省略号/破折号保持两格及独立源字符；避免普通自然折行的孤立标点。末格汉字与点号已按 D-025 共格后，若还紧随不可合法放下的闭标点或连续点号，明确返回安全错误和原文位置，不回退前字、不裁字、不丢内容。字形大小与墨迹仍须真实样张和实印验证。

### 4.2.2 用户换行与段落原文保留

**已确认：**用户输入或粘贴的显式换行及空行默认保留，不自动删除、合并、拆分段落，也不改写文字。格子或行带空间不足产生的自动折行仅存在于排版结果，不应反向改变输入内容。首行缩进通过布局规则表达，不通过往正文插入空格实现。

当粘贴内容含大量不合适的换行时，用户可明确触发「整理换行」；默认不执行。转换、差异预览与撤销按 [UI_DESIGN / D-046](UI_DESIGN.md)，实现放在编辑业务层，排版内核永远不自动整理。

技术处理可以统一行结束符的编码表示，但须保留全部显式换行及空行的顺序和数量。**已确认**一次显式换行即开始新段落；连续两次显式换行表示段落之间还有一整行空白。自动折行只是当前段落在下一行继续，不另起新段、不添加二次缩进。

### 4.2.3 段落与空行默认行为（已确认）

| 输入情况 | 版式行为 |
|---|---|
| 一段文字填满当前行 | 引擎自然续行，仍属同一段，不重复首行缩进 |
| 用户输入一次回车 | 当前段结束，新段从新一行开始，按当前模板的默认首行缩进 |
| 用户连续输入两次回车 | 新段开始前保留额外一行空白，新段仍按默认规则缩进 |
| 用户有更多连续回车 | 额外空行不得无故丢失；需测试跨页时逐行保留 |
| 当前页空间不足 | 以既定格数和书写区域分页，不缩放格线、不裁切文字；分页不等于新段落 |

**例子：**正文 `第一段。\n第二段。` 为相邻两段；`第一段。\n\n第二段。` 在两段之间额外留一行。以上约定适用于所有支持段落的模板，田字格、米字格也不例外；各模板首行缩进的默认具体数值可以不同。

文本的首行缩进属于排版样式，不会向原文添加空格；用户本身输入的空格仍应保留。标题是独立文本块，不受正文首行缩进约束。

### 4.2.4 英文和数字按真实字形宽度排版（已确认）

- 在作文方格、田字格和米字格的填字模式下，英文和数字都采用**测量后的实际显示宽度**，而非「一个字母一格」或「固定 N 个字母一格」。
- 一段连续的英文字母组成的单词优先作为一个换行单元；如果当前行剩余空间不足而下一行能容纳，就从下一行放置整个单词。单词本身也可能占据多个连续格位，**并不是每格只能画一个字符**。
- 方格单元的物理尺寸不变；拉丁文本只能在可用格位内布局，不能越过页面边界。字形测量需要与 PDF 使用一致的字体与文字尺寸基准，Canvas 预览必须与导出结果验收对齐。
- **一套默认断行行为**：当前行放不下的英文单词直接整体移至下一行；只有当单词本身长过整行时，才按完整 Unicode 字符（grapheme cluster）边界拆分续行，不能切开组合字符或丢字，也不改写原始单词。
- 连续数字、带小数点的数字（例如 `3.14`）优先视为整体安排；超出整行时同样以安全边界续行，绝不越界。保留原文的正常空格及其作为单词分隔的意义，自动折行不改写用户输入。
- 不向用户提供「每字母几格」「英文断词策略」「数字占格模式」等额外开关。混合标点的极端排版边界仍需布局测试，但不因此添加多套用户模式。
- 英文字母练习若以后另有「一字母一格」需求，应作为不同的学习内容场景再评估，不因此让现有作文/田字/米字格增加开关。

## 4.3 自动空白/填字与主动描红（已确认）

**首版用户操作**：选择模板后即可生成完整空白纸；输入内容即显示普通填字；若想制作描红练习，则主动开启一次「描红」。用户端不提供三个模式的必选下拉框，也不提供字号、描红深浅滑块。

**引擎模式推导**：先根据实际要绘制的标题、正文等内容判断是否存在可显示文字；无可显示文字时采用 `blank`，有文字且描红未开启时为 `filled`，有文字且用户主动开启描红时为 `tracing`。即使只有空格/换行，原始输入仍保留在编辑器，不因推导空白模式而改写；具体空白占位的界面反馈需要测试。

**统一布局**：`filled` 和 `tracing` 应先获得相同的文字定位、跨格映射、换行与分页。最终仅在绘制时改变参考字的颜色/深浅等样式；描红不能通过另起一套布局计算改变文字占格。正常填字的字号由模板固定文本预设决定，描红复用同一字号。格线全部照常绘制。

**打印约束**：后台维护印刷友好的字体、文字尺寸与描红灰度（具体值待实际样张确认）；Canvas 预览和 PDF 都读取同一版预设。不能把未经打印验证的灰度/字号暴露成用户自由滑块。若描红开启但没有可显示文字，仍生成正常的完整空白纸，不制造空白描红状态错误。

## 4.4 拼音输入的首版确定规则

- 拼音纸支持用户**直接输入**拼音文本，例如 `nǐ hǎo`，带声调与不带声调的文本均可交给排版器。
- **不提供汉字转拼音、自动选读音或多音字消歧**；如果用户输入汉字，不能悄然把汉字转换成猜测的拼音。是否给出格式提示由 UI 方案讨论，不应静默改写原文。
- 直接输入不等于无需文字处理：仍需要正确识别 Unicode 组合字符、声调位置、音节边界和空格，根据四条书写线决定字母与调号的垂直位置，并在行尾安全换行。
- 这一轮确认的是**输入边界**；字体选择、拼音音节及断行算法、拼音线上的实际字形位置仍属于 [文字布局技术验证](DECISIONS.md) 的 O-003，不能宣称已经实现。

### 4.5 方格文字布局内核的首轮实现

`packages/paper-core/src/layout.ts` 提供 `layoutSquareDocument`，输入固定版本的方格预设、可选标题/正文和描红开关，输出每页完整的 `PageGeometry` 和文字毫米坐标。支持标题逐行居中，正文首行两格缩进，真实显式换行/空行，正常续行不重复缩进，句号等行尾点号与汉字共占末格，自动跨页且每页仍保留完整格线。仅有格位/坐标，无 PDF 或 Canvas 绘制，也尚未接入微信。

当前实现中，英文、数字和空格的度量通过调用方提供的 `measureTextMm` 回调完成，**遇到需测宽的内容时，没有字体度量不能凭假数字静默生成英数排版**。正式接入须按 D-032 使用两端共用的字体度量模块和版本固定的数据，不能让 Canvas/PDF 各自测宽决定分页。开发测试使用可预测的模拟回调，不代表 MiSans 字宽或版本一致性已验收。长单词在整行放不下时按 Unicode grapheme 边界切分；页数达到明确上限时抛错，不交付部分内容。

本阶段仅覆盖三种方格模板；拼音是行带，不得用该方格排版 API。中文复杂标点、字体选择与真正字形绘制、Canvas/PDF、手机客户端的 `Intl.Segmenter` 支持需后续验证；样张显示也还没有最终字体验收。本阶段标题和正文之间采用暂定**一行空格线间距**，属于技术默认值，仍可根据真实样张在固定模板预设中调整，不向用户新增选项。

## 5. 首版输出：Canvas 预览 + PDF 打印

### Canvas：小程序本地预览

根据 `LayoutPages` 在微信端渲染，保持纸张真实宽高比。放大/缩小只影响显示；不修改格宽和分页；预览不调用生成云函数，不扣次数。

### PDF：唯一正式导出格式

CloudBase 云函数根据同一份布局生成 PDF。它是首版打印交付物，必须验证：
- 页面的真实物理尺寸、固定中心线几何留白，以及完整墨迹在已验证打印安全区域内的边界；
- 格线完整且没有任何跨界、遮挡或裁切；
- 标题、正文、标点及拼音的文字位置，长文自动续页；
- 中文字体可用性、授权、必要的嵌入、缺字处理与文件大小；
- 微信打开和实际打印（避免打印对话框“适合页面”二次缩放造成测量误差）。

### 首版字体分配与描红（D-031）

**Owner 已确认字体分配，实施与打印验收待完成。** 本表为各模板普通填字/描红字体分配的权威说明，用户不选择、不切换字体：

| 模板 | 普通填字 | 描红 |
|---|---|---|
| 作文方格 | MiSans | MiSans，改为浅灰 |
| 田字格、米字格 | MiSans | 中文参考字使用霞鹜文楷 GB（LXGW WenKai GB），浅灰 |
| 拼音四线三格 | MiSans Latin | MiSans Latin，改为浅灰 |

作文方格与拼音四线三格开启描红时沿用普通填字的字体，只改变深浅；霞鹜文楷 GB 的中文描红分配限定于田字格、米字格，不能概括成“所有中文描红”。具体字重、字号和浅灰强度由预设经验证确定，描红复用填字字号；拼音声调和四线定位仍须验证。此次范围确认不代表字体许可、字形边界或实体打印已通过。

**逻辑排版与字体渲染是两层**：普通填字、描红共用内容拆分、逻辑占位、对齐、换行及分页结果。描红允许采用专用字体，故字形轮廓和字体度量可不同；字体渲染器必须将具体字形安全置于预先确定的格位/行带中，不得因为换了字体就改变固定格数、页数或原文。当字形无法在既定位置正确呈现时，应在开发/验收阶段处理，而不是向用户暴露字号和选字体选项。

**版权与部署限制：**
- **MiSans**：官方确认免费商用和嵌入，软件中需明确注明使用 MiSans；禁止单独再分发和改编字体。PDF 按字子集嵌入、字体随小程序分发的许可解释与实际落地方式仍需确认，不能将 MiSans 误认为 OFL 字体；在合规方式未经确认前不可直接作为可交付实现发布。
- **霞鹜文楷 GB**：SIL Open Font License 1.1，可免费商用、嵌入和依许可再分发；再分发需包含 OFL 许可文本。作者明确指出仍有部分笔形保留印刷风格，**未必适用于笔画规范要求极高的少儿字帖**，因此不能在宣传中宣称该字体符合官方规范书写教学要求。小学常用字需要通过人工对照和纸质描红样张验收。
- 优先减少字体文件数量和包体积；字体与缺字回退必须可预测，Canvas 与 PDF 的占格及分页一致。字体文件不得由程序直接发送给终端用户作为下载商品。

**资源准备**：已从官方取得三种 Regular 开发候选及许可证，版本、来源、散列与检查范围见 [字体资源清单](../assets/fonts/README.md)。这不改变本节待验收状态，也不冻结最终字重。

**验收顺序**：按上表，用已确认的 A4 格纸和行带规格分别输出普通填字与描红样张，包含作文方格的 MiSans 浅灰描红、田字格/米字格的霞鹜文楷 GB 中文描红，以及 MiSans Latin 带调拼音；比较常用汉字（包含笔画、点、钩、折）、标点、中英数、声调与高低字母、PDF 嵌入和实际黑白打印灰度；确定字重、字号、浅灰、字体资源体积与许可交付方式后，才完成技术选型验收。

## 6. 正确性与一致性

不要求跨渲染器像素级一致；需要：
- A4 等物理尺寸正确，打印为 100% 比例时中心线格宽、几何留白及完整墨迹分别按 D-038 检查，测量公差需实印确定；
- 页数、行列位置、正文占格和分页符合规范；
- 首版只提供 PDF 下载，不在页面显示尚未支持的 Word 入口；
- 所有调整能复用同一套测试样本，避免“改作文格影响米字格”。

初步公差及样张尺寸将在 PoC 期间确定，不能凭空规定毫米级指标却不实测。

## 7. 技术验证顺序（下一轮讨论重点）

1. 根据 [已确认首版规格](PAPER_PRESETS.md) 构造四种模板几何数据与基准测试，确认实际打印边界、线宽和清晰度（不要再重新选择格数）。
2. 确定通用文字块的对齐、缩进、自动换行、标点、空格、英文和段落规则，验证作文格/田字格/米字格可共享。
3. 做 A4 整页作文格两页样张，与原始两篇作文效果对照。
4. 做田字格、米字格、拼音格 PDF 样张，检查辅助线/虚线。
5. 以 PDF 为主要交付样张，检查安全留白、溢出续页及没有内容截断。
6. 确定测试向量、字体方案，再连接微信预览与云函数。
