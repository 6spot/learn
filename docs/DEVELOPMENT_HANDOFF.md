## 2. 可以视为已确认的开发输入

- 微信原生小程序 + 关联 CloudBase，首版只交付 PDF，其他技术栈及高级业务不随意增加。
- 四种纸张均为固定 A4 竖版，每模板只有一个当前发布规格；无用户格宽、边距、格数选择。几何数值按 [D-038 中心线定义](PAPER_PRESETS.md#21-中心线墨迹与打印安全区域d-038) 计量，完整墨迹与打印安全边界另行验收。
- 无字直接生成完整空白纸、有字默认填字、描红主动开启；无字号/灰度/字体选择器。
- 标题、段落、缩进、标点、英文数字、跨页及原文保留按已确认 D 项；两端按 [D-032](ARCHITECTURE.md#31-共享排版代码与版本匹配d-032) 共用排版源码、匹配版本并核对布局，Canvas/PDF 渲染器**不能自行决定分页**。
- 默认字体按 [D-031 分配表](PAPER_ENGINE.md#首版字体分配与描红d-031) 使用，注意作文方格描红沿用 MiSans，霞鹜文楷 GB 中文描红仅用于田字格、米字格；已从官方取得三种 Regular 开发候选，路径、版本及来源见 [字体资源](../assets/fonts/README.md)。具体嵌入/分发许可、字形及打印仍待验证。
- 模板**格线算法由代码定义**；固定尺寸和默认样式以 CloudBase 中可信的已发布不可变版本为准，预览与云端导出锁定相同版本。不建大型 CMS。
- 用户身份、额度、成功扣次、任务和文件权限由可信云端验证；不默认持久保存作文正文。[D-036](DATA_AND_CREDITS.md#43-不保存正文的恢复边界d-036) 已确认恢复仅处理状态、已有 PDF 和账本，不保存正文供自动重试；失败后用户需要时重新粘贴生成。
- 打开小程序时由应用入口统一检查版本，页面共享结果；受理后的生成任务独立于页面运行，通过“我的 → 生成记录”查看结果。已实现 [D-033 更新流程](ARCHITECTURE.md#32-不受支持版本的微信更新流程d-033)、[D-034 结算规则](DATA_AND_CREDITS.md#4-可信任务状态机d-034) 及 [D-035 记录体验](PRODUCT.md#41-生成记录与离页体验d-035) 的本地组合；真实微信发布更新、CloudBase 生命周期和手机文件打开仍需外部验收。

## 3. 当前真实进度与优先顺序

已交付四模板真实字体布局/摘要、Canvas/PDF、可信账户/预设、幂等受理与结算、中断恢复、记录与私有领取、统计和有限隐私清理。八个原生产品页面已接线，App 统一持有兼容、编辑、生成、记录和本地清理状态；未知生成结果沿用原请求，后台迟到结果不抢跳。详细检查与当前官方模拟结果见 [ROADMAP](ROADMAP.md#当前开发检查点2026-10-11)。模拟服务复用真实业务/PDF 包，但并未实际部署 CloudBase。

1. 新 checkout 运行 `npm run setup`，按 [字体资源](../assets/fonts/README.md) 恢复原文件，并安装 [TESTING](TESTING.md) 指定的本地 Python 工具依赖。
2. `npm run build` 可从干净源码直接构建；微信开发者工具导入仓库根目录，配置自动选择 `dist/miniprogram`。生产配置未填写时正常显示服务不可用，不静默使用测试账户。
3. `npm run test:all` 运行全部本地回归；`npm run test:product:devtools` 使用官方自动化连接内存模拟服务，必须串行占用开发者工具。当前独立检出检查为 519 项 Node、20 项 Python 通过，历史结果不能代替改动后的验证。
4. 真实配置按 [发布顺序](CLOUDBASE.md#6-最终配置与发布顺序) 最后执行；正式构建为 `npm run build:release -- --config <公开配置路径>`，导入目录为 `dist/release`。
5. 已归档本地任务不重新建项。剩余外部条件集中由 T24 和 [最终清单](FINAL_ACCEPTANCE.md) 跟踪；具体代码位置以 [架构目录](ARCHITECTURE.md#4-当前代码组织) 为准。

## 4. 最后交给 Owner 的事项

- 确认候选 Regular 字体的分发/嵌入用途许可、正式字号/灰度/拼音基线和教学字形；当前缺字明确拒绝并保留原文，不回退系统字体。正式字体和打印验收不能被代码归档代替。
- 配置 CloudBase 环境、权限、资源和保留数值、管理员及可信维护调度，并实际验证事务/执行生命周期、隐私告知与清理。预设发布接口已经实现，正式版本必须附真实验收证据。
- 完成手机键盘/安全区/内存/更新、至少两账号权限与 PDF 打开，以及四模板 100% 实体打印量测。标题对齐、正文缩进和 D-046 整理/撤销已实现，无须等待另一次功能开发。
- 个人主体支付/激励广告可用性、次数包价格、广告奖励数值，以及后续 DOCX/其他工具：保留未来边界，不是先做纸张 PDF 闭环的前置条件。

当现有文档互相冲突时，以 [DECISIONS](DECISIONS.md) 的已确认决策与 [PAPER_PRESETS](PAPER_PRESETS.md) 的物理规格为准；暂停做会改变产品体验的新取舍，提交决策说明让 Owner 确认。**可独立验证的工程细节不必逐项请求 Owner 同意。**
