- [ ] 核对最终集成验收依赖（不等同于全部启动条件，分阶段输入见下文及父任务总表）：[T08 实现 Canvas 预览](../archive/2026-10/10-10-v1-canvas-preview/prd.md)、[T09 实现 PDF 渲染](../archive/2026-10/10-10-v1-pdf-renderer/prd.md)

## 分阶段交付

A：随 T08/T09 稳定产物分批准备量测表、字体/格线样张；B：完整四模板、正式用途许可、屏幕/PDF与实体打印全部通过。T12 正式 active 发布只能消费 B。

阶段输入与整项验收依赖以 [父任务总表](../10-10-learn-v1/task-map.md) 为准；只完成阶段不能将整项标记完成。

## 交付步骤

- [ ] 设计量测表及正式字体样张矩阵。
- [ ] 执行黑白实印、人工字形检查与跨输出对照。
- [ ] 将通过的样式参数写入可信预设，失败项追溯到所属模块。

## 验收映射

- [ ] T10-AC1：四模板空白、填字、描红及多页样张齐全，Canvas/PDF 逻辑位置一致。
- [ ] T10-AC2：按 A4/100% 实印测量中心线、完整墨迹与打印安全边界，记录设备、参数及公差。
- [ ] T10-AC3：完成字形、声调、字重/字号、灰度和缺字策略验收；不宣称霞鹜文楷为官方规范教学字体。

## 验证与收尾

- [ ] 执行 A4 + 100% 实际大小实体打印，记录中心线、完整墨迹、安全区域、设备与量测结果；缺少实印证据不通过。
- [ ] 检查文档差异、相对引用及与 DECISIONS/PAPER_PRESETS 的一致性。
- [ ] 将本轮实际验证、失败原因与剩余项目记录到任务证据；必要时更新 TESTING/ROADMAP。
- [ ] 检查无正文、敏感凭据或未授权字体分发进入日志/提交。
- [ ] 独立检查通过后再标记完成，恢复/回退不得覆盖他人变更。

## 当前验收限制

实体打印需有实际设备和人工量测；无法实测时保留未通过状态。
