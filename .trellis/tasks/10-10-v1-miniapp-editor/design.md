## 实现边界

1. 当前只有开发诊断页；新增 P01 templates、P02 editor、P03 preview，以及满足原生双 tabBar 的 P04 最小承接页。P04 的账户/记录功能由 T21 后续接通，不新增结果页。App 改为持有唯一编辑会话；逐入口打包不能依赖 Page 模块 singleton。
2. `miniprogram/lib/editor-session` 管理唯一内存草稿、锁定预设、布局/摘要、异步版本及整理/撤销；`editor-environment` 注入可信预设和原字体加载。页面通过 `getApp()` 访问共享实例，保留切页/返回与切模板的原输入，不向 storage、路由、分享或日志写正文。T19/T20 后续通过 App 集成兼容状态/真实提交依赖。
3. 使用 T07 `layoutPaperDocument` / `createLayoutDigest` 和 T08 Canvas，不另写排版。空白不强制加载文字字体；有字加载必要原字体，旧异步结果不能覆盖新输入。首次选择锁定模板预设，自动 active 更新不改变正在编辑的版本。
4. 首页四象限白底、编辑同页正文优先、描红独立可见、进阶默认折叠。原生 textarea `maxlength=-1`；展开/描红不重建输入节点。编辑顶部由同一整页布局裁取完整行片段，固定本模板高度；拼音片段为 52 mm、三个完整行带，确保单行标题及空行后仍显示首行正文。官方模拟器发现原生 Canvas 不受祖先 overflow/transform 可靠裁剪，故组件/渲染器增加可选 `viewport:{topMm,heightMm}`，实际位图高度即片段高度，仅平移显示坐标，仍预检整页资源/墨迹，不改变排版/摘要。P03 单页画布、分页及页内放大/还原，滚动可达纸张四边，不弹第二预览层。
5. D-046 在 UI 会话层独立实现：逐个保留 CR/LF/CRLF 与全部空白；仅合并非空行之间、前行无句末标点且后行非列表/缩进的单边界；拉丁/拼音词边界必要时补空格。显示原输入的前后对照，应用再次核对正文版本/内容；取消无变化；一层撤销只因后续正文编辑失效，标题/描红/设置不影响。
6. 官方模拟器亦发现 P03 原生 Canvas 越过 scroll-view 遮住翻页操作；P02/P03 因此请求 `snapshot:true`：隐藏 Canvas 按同布局绘制，以 `toDataURL` 输出当页内存 PNG，原生 image 解码后再标就绪。单次 data URL ≤900,000 字符；编码后位图归还 1×1；换页/离页清空内存图片并取消过时加载，不写临时文件。直接 Canvas 保留给诊断/首页，不改 PDF。缺失 API、编解码失败和资源限额均明确失败。
7. 本轮改动限定 App/共享样式、上述页面、会话/环境/清理函数及必要原生声明、T18 测试/官方模拟器脚本，以及上述必要 Canvas viewport/snapshot 兼容修复；根构建和脚本集成由 main 协调。生成按钮按实际依赖就绪状态禁用并解释，T20 前不伪造成功。
8. 本地测试任意整理样例、版本锁定、异步竞态、设置及单例跨入口；官方模拟器以固定合成输入驱动真实控件/Canvas，截图明确模拟器来源。真机键盘、焦点、内存性能及分发配置留最终验收。

## 跨层约束

- 纯 TS 排版拥有文字占位、换行、分页；Canvas/PDF 仅绘制；云端编排拥有鉴权、额度和任务结算。
- 物理规格取自 PAPER_PRESETS，文字/字体取自 PAPER_ENGINE，兼容性取自 ARCHITECTURE，任务信任规则取自 DATA_AND_CREDITS；本任务不另建权威副本。
- 平台实际能力、资源版本与生成交付须有证据；Mock、配置草案和预备字体不得标为上线验收通过。

标题对齐与缩进使用 T03 的共享文档契约，T14 校验允许值并纳入参数指纹；两端复算采用同一设置，不覆盖可信字体或几何预设。

## 兼容、发布与回退

只在责任模块内推进，保留已有行为及基准。涉及排版时发布新的受支持组合，保留在途任务所需旧资源；涉及云端状态时不得以代码回退反转成功/失败终态或直接改写账本。具体部署/回退步骤随选定方案补充后再执行。
