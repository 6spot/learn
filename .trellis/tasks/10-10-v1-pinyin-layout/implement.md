# T06 执行清单

## 启动条件

- [ ] 核对 [PRD](prd.md)、[设计](design.md)、权威文档及本次工作区变更。
- [ ] 核对最终集成验收依赖（不等同于全部启动条件，分阶段输入见下文及父任务总表）：[T03 完善通用文档与布局契约](../10-10-v1-document-contract/prd.md)、[T04 接入共享字体度量](../10-10-v1-font-metrics/prd.md)
- [ ] 将技术未知项落实为可验证方案；涉及新产品取舍先按 DECISIONS 流程确认。
- [ ] 细化设计后完成执行前评审；按 Trellis 流程启动本子任务，不以父任务代替实现任务。

## 分阶段交付

A：按 T03 行带契约和度量接口实现独立拼音布局；B：验证真实调号、基线、升降部、多页与渲染输入，不复用汉字格坐标。

阶段输入与整项验收依赖以 [父任务总表](../10-10-learn-v1/task-map.md) 为准；只完成阶段不能将整项标记完成。

## 交付步骤

- [ ] 根据真实字体设计行带承载与基线计算。
- [ ] 实现音节换行、显式段落和自动续页。
- [ ] 生成布局基准与基线样例交 T09/T10 渲染验收。

## 验收映射

- [ ] T06-AC1：支持带调/不带调拼音与 Unicode 组合字符，保持音节、空格、换行和跨页顺序。
- [ ] T06-AC2：标题、对齐、缩进按行带模型表达，不调用汉字方格坐标算法。
- [ ] T06-AC3：MiSans Latin 的字母、升降部与声调基线经真实字形验证；格线坐标固定不变。

## 验证与收尾

- [ ] 在 `packages/paper-core` 执行 `npm test`（包含 TypeScript 编译）；缺依赖先 `npm install`。涉及布局时更新基准，并将渲染/实印剩余项交 T10。
- [ ] 检查文档差异、相对引用及与 DECISIONS/PAPER_PRESETS 的一致性。
- [ ] 将本轮实际验证、失败原因与剩余项目记录到任务证据；必要时更新 TESTING/ROADMAP。
- [ ] 检查无正文、敏感凭据或未授权字体分发进入日志/提交。
- [ ] 独立检查通过后再标记完成，恢复/回退不得覆盖他人变更。

## 当前验收限制

基线、字重/字号尚待验证；不得做汉字转拼音或静默修改输入。
