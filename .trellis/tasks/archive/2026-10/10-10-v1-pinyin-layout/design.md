# T06 拼音行带实现设计

> 2026-10-11：本地开发候选；真实字形量测用于代码验收，设备、字体许可和实印仍交最终验收。

## 改动边界

当前已有共享文档/真实字体及三种方格布局，但没有拼音布局。新增 `packages/paper-core/src/pinyin-layout.ts` 独立实现固定行带文字，不调用汉字格坐标或套用方格分页。内部共享安全 shaping/cache 小函数，原方格布局基准不变；新增合成/真实字体测试和布局基准，导出 API 并更新候选版本。无需 UI、平台 API、文件 I/O 或渲染器依赖。

## 文档与断行

`layoutPinyinPaperDocument(document, metrics)` 返回既有 `PaperLayout`。重新验证输入/可信预设并重建派生文档；资源组合不一致立即拒绝。原文、UTF-16 ranges、CR/LF/CRLF、末尾空段均保留，不在内核整理或规范化输入。

字母、带调预组字符、组合声调按完整 grapheme 处理；不做拼音转换或拼写校正。字符边界采用固定白名单：ASCII 字母/数字、常用 ASCII 标点、弯引号、拼音预组字符、六种拼音组合标记及可度量空格；每字符簇至多一个声调，ü/ê修饰仅用于u/e且至多一个（含预组等价ế/ề）。汉字、其他脚本、emoji、不可可靠绘制字符明确拒绝。连续非空格片段（含隔音符/标点）作为一个 run，优先完整换行；仅 run 超过整行时按完整 grapheme 分段并重新 shaping，每一个原始空格单独保留。边界不靠隐式补空格或删空格改善视觉。

正文每个显式段落首行缩进为预设单位，自动续行不缩进。标题逐行左/中/右对齐；标题/正文间隔按预设行数。行带耗尽自动新建完整同规格纸张；超页上限返回安全错误，不交付部分文字。无可绘制文字时按 D-028 返回一页完整空白纸。

## 实测垂直定位

固定几何唯一来源仍是 [PAPER_PRESETS](../../../../../docs/PAPER_PRESETS.md)：四线行带使用其 `lineGapMm/groupGapMm/groupCount/lineLengthMm`，没有 cell/column 概念。

MiSans Latin Regular (1000 units/em) 抽样覆盖字母 a-z、所有拼音预组调号、大小写和 ê/m/n 组合调号：x-height 530，升部上界754，降部下界-224，带调上界1070。旧字号8mm会让最大调号越过顶线0.56mm。因此候选字号改7.4mm，基线仍是第三线(top+8mm)，实际墨迹范围 top+0.082 至 top+9.6576mm；x-height 3.922mm，接近中格4mm。这是版本化的字体适配，不修改格线，也不对单字动态缩放/平移基线。

整行使用同一固定基线。run 宽度由 advance 与真实左右 overhang 的并集决定；额外左 overhang 留在自身 slot 内。每个字形实际墨迹必须在行带 slot 与固定几何范围内；重复/非法调号、越界字形、缺字/错误度量安全拒绝。filled/tracing 均使用 MiSans Latin，slots、glyphs、行和页保持一致，只有 mode/灰度不同。
