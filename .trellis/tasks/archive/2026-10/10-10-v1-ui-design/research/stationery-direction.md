# 历史视觉尝试：纸本文具

> 此稿已被 Owner 否定，当前方向以 DECISIONS D-041 与 UI_DESIGN 为准：实际白纸、冷白界面，同时重做构图；不要继续沿用下方暖色候选值。

Owner 在第三稿后仍不满意整体审美，并明确选择：**纸本文具感，暖白、墨黑、少量强调色，纸张清楚，安静而有质感**。

首页四象限、详情明确区块层级继续保留。不能只替换主色；先把首页和编辑页的纸张存在感、字体层级、对齐、疏密做好，再让其他页面沿用同一套视觉语言。本轮仍为规划阶段的可交互设计稿。

## 设计执行目标

- 暖白页面与略亮的纸张形成自然区分，墨黑用于主要文字和主按钮，少量朱砂色用于强调和当前选择。避免之前灰绿、灰字和细线都落在相近色阶里的发闷效果。
- 四象限用留白组织，不需要大十字表格线或四个大圆角卡。纸张本身够大且格线可辨；不得把纸张放进额外的内底板。
- 首页的纸张缩略图提高屏幕示意对比度，增强四种格线的可辨识度；这些仅是 UI 示意，不改 PAPER_PRESETS、正式字体、打印颜色/线宽或排版代码。
- 字体有角色：页面标题与模板名可尝试设备自带宋体/serif，表单标签/正文/按钮仍用系统无衬线。不要新增下载字体或把纸张字体分配移作 UI 字体；系统宋体的真机可用性及回退要在定稿前验证。
- 编辑页仍是预览、文字内容、排版设置三个全宽区块，通过色温、标题、间隔划分。不要增加营销文案或把所有区块做成等重、等高的表单面板。
- 一处真实纸张边缘与极轻纸张阴影可以表达纸张；不是给纸张外套卡片。避免噪点、旧纸纹理、卷角、胶带、随机旋转等文具拟物装饰。
- 保留 D-040 的描红、默认收起进阶和整理预览/应用/撤销；本轮不改变实际文本转换边界。

## 拟采用的视觉值（待看稿评审）

页面暖白 `#F5F2EB`，纸白 `#FFFEFA`，墨黑 `#292723`，次要文字 `#777168`，分隔 `#DCD6CA`，朱砂强调 `#B75036`。主按钮优先墨黑，避免整页铺强调色。实际 CSS 若微调，同步 UI_DESIGN；这些不是正式纸张打印参数。
