# T22 原生运营页面设计

2026-10-11：按 P08、D-049 与现有原生视觉基线实现 `pages/admin/index`。root 已接受日期选择及接入点；后端契约见 [design.md](design.md)，本文件只定义前端职责。

- 页面从唯一 `getLearnApp().client` 调用 `getAdminStats`；不创建 transport、登录或权限状态机。入口由 T21 按云端 `account.isAdmin` 显示，绕路进入仍实际调用鉴权接口。App 类型、入口和路由注册由集成所有者完成。
- 默认不传日期，由服务器决定上海当日；原生日期 picker 上界使用响应 generatedAt 对应上海日期，不取设备时区。可选历史日期或返回“今天”，进入与主动刷新查询，不轮询。
- 使用白底分组、横线与双列文字展示新增、有效活跃、成功、失败、失败率与额度消耗；四模板列表只展示成功任务数。不给 CMS、改余额或用户原始记录入口。
- 服务响应经有限的日期/数值/覆盖与四模板结构校验后，只投影为固定标签与数字。无终态分母显示“暂无”；缺口对应指标显示“不可用”，列出每个来源的覆盖起点与缺口原因。显示上海统计时间及刷新口径，不声称数据库时间点快照或实时推送。
- 重复刷新共享当前请求；切换日期、离页使旧响应失效。网络/扫描/覆盖变化失败保留上一份成功汇总，明确标注其原日期及“本次未更新”，绝不贴上新查询日期。权限失效、账户禁用/删除立即清空旧指标。离页清理成功汇总与订阅，在途请求不会更新隐藏或卸载页面。
- 仅保存页面内存数据，不写存储、不记录原始错误、不返回分享截图。测试先用 ES2017 VM 与实际 CloudClient 安全响应协议；官方模拟器与真实本地服务集成由 root 协调占用后进行。真机、真实 CloudBase 权限和配置仍留 T24。

本阶段只修改 admin 页面、`admin-session.ts`、admin 测试及本任务前端设计/证据，不改 App、P04、公共构建或后端。
