# T22 实现最小运营中心

## 目标

Owner 能查看必要使用量、失败与额度消耗，且普通用户无法越权。

## 已确认背景与范围

- 本任务来自用户于 2026-10-10 同意的 [V1 总计划](../10-10-learn-v1/prd.md)。
- 责任范围：小程序管理员页面、云端聚合统计与审计。目录名称表示职责，尚未存在的模块不得描述为已实现。
- 已有四模板几何与基础方格文字布局可复用；本任务不能以历史测试或占位字体样张代替验收。
- 最终集成验收依赖：[T13 实现身份与免费额度](../10-10-v1-identity-credits/prd.md)、[T15 实现生成执行与事务结算](../10-10-v1-job-execution/prd.md)；T25 界面基线已满足。

## 要求与验收

- **T22-AC1**：每次管理员 API 可信鉴权，绕过页面不能读指标或改配置。
- **T22-AC2**：新增、成功生成、失败率、模板使用与额度消耗可回溯原始安全记录，重试不重复统计。
- **T22-AC3**：配置/额度敏感操作有审计；不展示正文，不建设独立后台或 CMS。

## UI 设计依赖

D-043 已接受 [T25](../10-10-v1-ui-design/prd.md) 当前稿为功能开发基线，O-015 本轮看稿关闭。页面按 [UI_DESIGN](../../../docs/UI_DESIGN.md) 与前端规范实现，样式细节后续迭代；O-014/O-007/O-009 等独立决策不因 UI 确认而关闭。

## 验收条件与待验证事项

DAU 有效操作集合和刷新频率未定前不宣称指标已验收。

本任务可以先完成不依赖外部条件的调研与准备；条件未满足时，相应验收项保持未完成。技术细节在执行前结合实际源码补齐设计。

## 不在范围

不改变已确认四模板物理规格，不增加第二套排版策略或未确认用户选项，不实现支付/广告、DOCX、AI/OCR、独立服务器、Web 后台或通用框架。与本任务无关的已有工作区修改保留。
