# 字体许可逐用途核对

2026-10-10 基于仓库内原件核对。原件、来源 URL、大小和 SHA-256 以 [manifest.json](../manifest.json) 为准；本说明是工程交付条件核对，不把字体元数据当作额外授权。字体分配与上线门槛仍由 [PAPER_ENGINE / D-031](../../../docs/PAPER_ENGINE.md#首版字体分配与描红d-031)、[O-004](../../../docs/DECISIONS.md) 维护。

## MiSans / MiSans Latin

依据：[小米原始协议 PDF](MiSans-License.pdf)，本轮用 `pdftotext` 读取。第 2 条授予免版税、全球、可撤销的版权许可，同时要求：

- 第 2.1 款：“您应在软件中特别注明使用了 MiSans 字体。”
- 第 2.2 款：“您不得对 MiSans 字体或其任何单独组件进行改编或二次开发。”
- 第 2.3 款禁止单独进一步分发字体及副本；说明该限制不适用于使用字体创作的其他作品，举例包括宣传素材、logo、App。
- 第 2.4 款要求任何字体副本保留版权声明和本协议。
- 第 7.1 款说明本协议取代先前陈述、承诺、宣传或许可协议。因此免费商用宣传或字体内部 `fsType=8` 不能单独解释所有交付方式。

| 使用方式 | 核对结果与交付条件 |
|---|---|
| 本地读取原始文件、度量/排版研发 | 按现有用户授权与原始候选开展，保持文件不变并留存协议；本仓库工具不分发字体 |
| 含嵌入字体的 PDF | 官方嵌入说明与协议作品例外可作依据；本协议未逐项定义 PDF 字体流。最终库如何嵌入、保留版权和协议仍需对应交付验证，未作生产通过结论 |
| PDF 子集化、格式转换 | 条款未明确子集化是否属于禁止的改编，**待验证**；库默认 subset 或 fsType 无禁止位不代替许可核对 |
| 小程序代码包附原始 TTF | App 作品例外相关，但是否属于允许的软件附带方式及如何附版权/协议待最终交付确认 |
| 静态 URL / CDN 下发 TTF 或子集 | 单独分发禁令相关，不能仅凭用于 App 就认定允许；**待验证**，不先公开下载端点再补说明 |
| 署名和保留原件 | 条文明确要求软件注明使用 MiSans；交付副本时保留版权和协议。后续界面/发布包须落实 |

保持本地候选模式，不提交字体或子集，不以轮廓转换、更名等方式绕过条款。最终许可核对材料应包含实际库、嵌入模式、是否修改字体表、客户端获取方式及署名位置。

## LXGW WenKai GB

依据：[OFL 1.1 原文](LXGWWenKaiGB-OFL.txt)，包含 `Copyright 2022-2026 LXGW` 与 `Copyright 2020 The Klee Project Authors`。许可明文包含 `embed, modify, redistribute`；Modified Version 定义包含增删组件和格式转换。

| 使用方式 | 核对结果与交付条件 |
|---|---|
| PDF 嵌入/子集化 | OFL 明文允许嵌入和修改；字体及派生字体保持 OFL，生成文档无需采用 OFL；最终 PDF 技术有效性另测 |
| 随客户端分发原始/派生字体 | 第 2 条允许随软件附带/再分发；每份副本包含作者版权及许可，可用独立文件或用户易于访问的元数据 |
| 命名与作者署名 | 第 3/4 条限制保留名称和作者背书；当前原件版权声明后未列出 Reserved Font Name，仍须核对具体派生物，不以作者名宣传背书 |
| 单独售卖字体 | 第 1 条禁止；不提供单独字体商品或用字体文件替代纸张 PDF |

许可核对不证明笔形适合规范要求极高的少儿字帖，也不证明描红字号、灰度或打印可读性。人工字形与实印留给 T10；三份候选继续排除于 Git。
